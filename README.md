## Deploy on GitHub Pages
1. Create a new GitHub repo (e.g. `yourusername.github.io` for a root domain, or any name for a project page).
2. Push `index.html`, `work-with-me.html`, `past-projects.html`, and `style.css` to the repo's default branch.
3. Go to repo **Settings → Pages**.
4. Under "Build and deployment," set Source to **Deploy from a branch**, branch: `main`, folder: `/root`.
5. Save. The site will be live at:
   - `https://yourusername.github.io` (if repo is named `yourusername.github.io`)
   - `https://yourusername.github.io/repo-name` (otherwise)
